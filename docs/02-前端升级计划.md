# 前端升级计划:达到教学系统(智解Lab)观感水准

> 背景:W1 交付的单文件 HTML 仅用于验证链路,观感不达标。本计划将前端正式化。
> 技术栈决策:**React 19 + Vite + Tailwind 4 + oklch 主题,与智解Lab 同栈**,主题变量与组件风格直接迁移,团队已有经验,软著技术脉络延续。不引入 Vue。

## 一、观感基准(从智解Lab 迁移什么)

| 元素 | 智解Lab 实现 | 迁移方式 |
|------|--------------|----------|
| 主题色彩 | oklch 变量体系(primary/surface/border + 深浅色) | 复制 @theme 变量块,主色改为无人机巡检色系(深青+暖橙) |
| 背景 | oklch 径向渐变 + 液态玻璃 | 同款 body 渐变与卡片玻璃(blur/border/白 5% 叠层) |
| 卡片 | rounded-2xl + 微阴影 + 悬浮微动 | 同款工具类组合 |
| 状态徽章 | 彩色胶囊(在线/离线/示例数据) | 同款样式,用于连接状态/引擎标识 |
| 字体层级 | 微软雅黑,标题加粗大字号,正文 muted | 同规格 |

## 二、信息架构(工具型单应用,顶栏导航,不做侧栏)

```text
雾巡 · 无人机巡检实时增强
├── 实时监控(主页)
│   ├── 视图切换:左右分屏 / 滑动对比(同一帧逐像素对比)
│   ├── 源连接(摄像头/RTSP/文件)+ 实时连接状态徽章
│   ├── 指标卡:FPS(高亮)/ 增强耗时 P50/P95 / 端到端 / 累计帧
│   └── 冻结取证按钮
├── 取证档案
│   └── 记录列表 + 原始/增强并排查看
└── 系统状态
    └── 引擎信息(当前占位引擎如实标注)/ 模型契约 / 指标口径
```

## 四、工程约定

- 开发:`cd frontend && npm run dev`(Vite 5173,proxy → 8600);
- 生产:`npm run build` → `frontend/dist`,FastAPI 优先托管 dist,旧单文件页保留为兜底;
- 所有指标展示均为真实接口数据;占位引擎在界面与状态页如实标注。
