# 场景决策:为什么选无人机巡检

> 结论:**无人机巡检**作为系统主场景。本文记录三个候选场景的完整对比与决策理由,便于答辩时回应"为什么是这个场景"。

## 三场景对比

| 维度 | 交通监控 | 无人机巡检(选定) | 车载辅助驾驶 |
|------|----------|------------------|--------------|
| 痛点叙事 | 雾天卡口画质差,取证困难 | 人工巡检危险/贵,雾天航拍影像失效,缺陷漏检 | 雾天 ADAS 感知退化,安全攸关 |
| 叙事强度 | 中(常见,评委审美疲劳) | **高(电力/输电线路巡检是国网真实刚需,故事新鲜)** | 高但敏感(安全声明难做) |
| 下游任务配对 | 车牌/车辆检测 | **绝缘子/杆塔/缺陷检测(公开数据集多)** | 行人/车道线检测 |
| demo 现场可行性 | 高(监控视频易得) | 高(雾天航拍视频易得 + 遥控无人机玩具可选) | 中(车载视角视频好找,但"安全"叙事易被追问) |
| 素材易得性 | 高 | **高(电力巡检公开视频/图库丰富)** | 中 |
| 与"实时增强"的贴合度 | 高 | **最高(机载算力受限 → 轻量化实时模型有天然动机)** | 高 |
| 风险 | 同质化严重 | 需要讲清"为什么不能事后处理"(答:巡检要现场决策) | 安全责任表述风险 |

## 选定理由(三句话)

1. **动机最硬**:输电线路巡检在雾天/霾天窗口期被迫停飞或影像报废,是电力行业的真实痛点,"实时"二字有天然正当性——不是 demo 需求,是作业需求。
2. **差异化最自然**:机载算力受限 → 你们组的轻量化模型正好回答"为什么不用离线大模型",工程侧的实时指标(FPS/延迟/模型体积)直接变成系统卖点。
3. **演示最稳**:雾天航拍视频素材丰富,现场视频文件兜底 + (可选)室内烟雾盒 + 玩具无人机,可控性远好于依赖真雾。

## 演示物料清单

- 必备:雾天航拍/巡检视频 2-3 段(输电线路优先),系统内循环播放;
- 可选:小型烟雾发生装置 + 摄像头(现场实时采集,冲击力最强);
- 兜底:预录屏幕演示视频(断电/设备故障时播放)。

## 命名建议(团队拍板)

- 系统名候选:「雾巡」「巡霁」「ClearPatrol」——建议围绕"巡检 + 穿透雾霾"意象,报名材料中英文各备一个。
