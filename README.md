# 无人机巡检实时视觉增强系统(UAV Real-time Dehazing)

> 面向无人机巡检场景的实时图像增强与感知系统。雾霾天气下巡检影像质量骤降,目标(绝缘子、销钉、异物缺陷)难以辨认——本系统对摄像头/视频流做**实时去雾增强**,并以"原始流 vs 增强流"双路对比展示,后续接入下游检测证明"增强让感知可用"。

## 当前状态(W1 骨架,如实标注)

- ✅ 完整实时链路:采集(USB / RTSP / 视频文件)→ 增强 → MJPEG 双路推流 → 前端分屏;
- ✅ 占位增强引擎:**经典暗通道先验去雾(He et al., 2009)**,纯 OpenCV 实现、无需权重——**这是占位引擎,不是实验室模型**;
- ✅ 截图取证(冻结对比入库)、基础性能指标(FPS / 增强耗时 / 端到端延迟);
- ⬜ W2:接入实验室真实模型 + YOLO 双路检测对比;
- ⬜ W4:React 工作台(当前为轻量单页,保证 W1 最快跑通)。

## 快速开始

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8600
# 浏览器打开 http://localhost:8600
```

默认尝试打开本机摄像头(源 0);无摄像头时在前端输入视频文件路径或 RTSP 地址(雾天视频可循环播放,作演示兜底)。

## API 一览

| 端点 | 说明 |
|------|------|
| `GET /stream/raw` | 原始画面 MJPEG 流 |
| `GET /stream/enhanced` | 增强画面 MJPEG 流 |
| `POST /api/source` | 切换视频源 `{"source": 0}` 或 `{"source": "rtsp://..."}` 或 `{"source": "D:/fog.mp4"}` |
| `GET /api/metrics` | 实时指标:FPS、增强耗时 P50/P95、端到端延迟 |
| `POST /api/freeze` | 冻结当前双路画面并存档取证 |
| `GET /api/captures` | 取证记录列表 |

## 模型交付契约(实验室组 ↔ 工程侧唯一接口)

```text
输入:  uint8 BGR 图像
输出:  同尺寸 uint8 BGR 增强图像
形态:  PyTorch 权重(.pth)+ 最小推理脚本(一图进一图出)
指标:  单帧推理耗时(注明 GPU 型号)
交接:  从 AutoDL 下载后放入 models/ 目录,工程侧编写适配器接入
```

契约一定,两侧并行:工程侧用占位引擎推进全链路,模型就绪后热替换。
